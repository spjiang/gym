## 1. 背景与目标

会籍办卡与门禁联动已交付。本切片补齐健身房业态的私教课包与团课排课预约核销，端侧仅 **Web 管理后台**（含教练工作台），会员小程序约课另开 change。

### 1.1 已确认决策

- 端侧：仅 Web 后台
- 团课满员：**不可约**；取消后释放名额
- 代约资格：本商户存在 **生效会籍** 即可（不按卡种细分）
- 支付：复用现有线下登记 + 线上 mock；真实微信生产联调不在本切片

## 2. 范围与边界

### 2.1 做

- 教练档案（归属商户、擅长、可授课说明、启停；绑定员工账号）
- 私教课包商品与实例：下单 → 支付 → 履约；核销扣课时
- 团课课程模板、场次排课、简单改派/代课
- 后台代约 / 取消；满员拒绝；生效会籍校验
- 团课签到（出席 / 未出席）；私教核销
- 教练 Web：本人课表、名下私教学员/剩余课时、上课核销（仅本人数据）
- 关键写操作审计

### 2.2 不做

- 会员小程序/H5 约课与购课
- 候补队列、复杂请假审批
- 真实微信商户进件与生产联调
- 库存 / 营销 / 报表 / 器材
- 门禁与课程自动签到联动
- 团课签到扣会籍次卡次数（一期不扣；若后续需要另开需求）

## 3. 领域模型

挂在健身房商户下，复用 `Order` / 支付履约钩子。

| 实体 | 要点 |
|------|------|
| Coach | `merchant_id`、关联员工、擅长、可授课说明、启用/停用 |
| PtPackageProduct | 名称、价格、课时数、有效天数、适用教练（全部或指定）、启停 |
| PtPackage | 会员持有实例：剩余课时、起止、状态（生效/用尽/过期/作废） |
| GroupCourse | 课程模板：名称、难度、默认时长、默认人数上限、预约/取消提前时限（分钟） |
| GroupSession | 场次：课程、教练、起止时间、教室/区域、人数上限、状态（开放/取消） |
| GroupBooking | 场次 + 会员；状态（已约/已取消/已出席/未出席）；同场同会员唯一 |
| CourseOrderLink（或等效） | `order_type=pt_package` 与课包履约关联 |

### 3.1 写死规则

- 已约人数 ≥ 上限 → 拒绝新约；取消 → `cancelled` 并释放名额
- 约团课须本商户有生效会籍，否则拒绝
- 私教核销默认扣 1 课时；剩余为 0 → 用尽；过期/作废不可核销
- 代课：更新场次 `coach_id` + 审计
- 并发约满：事务 + 行锁（或等效）与唯一约束，防止超卖

## 4. 关键流程

1. **售私教课包**：选会员 + 课包商品 → `pt_package` 订单 → 支付成功 → 履约生成生效 `PtPackage` → 审计  
2. **排团课场次**：课程模板 → `GroupSession`（教练、时间、教室、上限）→ 开放可约；改派教练写审计  
3. **后台代约**：校验场次开放、未满员、生效会籍、未重复预约、预约提前时限 → `booked`  
4. **取消预约**：在取消时限内（有权限角色可强制取消）→ `cancelled` → 名额释放  
5. **团课签到**：标记 `attended` / `no_show`；不扣会籍次数  
6. **私教核销**：选课包 → 确认 → 剩余课时 −1 → 流水/审计  

支付成功路径扩展：`order_type == pt_package` → `PtPackageFulfillment`（对齐会籍履约：失败可追踪、不静默丢支付事实）。

## 5. 权限、API 与前端

### 5.1 权限点

| 权限 | 用途 |
|------|------|
| `course:manage` | 课程模板、场次、改派、课包商品 |
| `course:book` | 后台代约/取消 |
| `course:checkin` | 团课签到、私教核销 |
| `coach:manage` | 教练档案 |
| `pt:sell` | 售卖私教课包 |

默认：商户管理员全开；前台 `book` / `checkin` / `pt:sell`；教练 `checkin` + 本人只读课表/学员；超管可跨商户。

### 5.2 API 分组（示意）

- `/coaches`
- `/pt-products`、`/pt-packages`、`/pt-packages/purchase`、`/pt-packages/{id}/consume`
- `/group-courses`、`/group-sessions`、`/group-bookings`

### 5.3 前端页面

- 教练管理；私教课包商品；会员课包列表/售卖/核销
- 团课课程；场次列表；场次预约名单（代约/取消/签到）
- 教练工作台：今日课表、名下课包与核销（数据范围仅本人）

## 6. 风险与验收

| 风险 | 对策 |
|------|------|
| 并发约满超卖 | 事务 + 行锁/唯一约束；超限拒绝 |
| 支付成功履约失败 | 订单保持已支付；履约状态可追踪/可重试 |
| 教练与员工脱节 | 创建时绑定员工；停用员工不可排新场 |
| 时区 | UTC 存储；展示沿用场地时区约定 |

**验收：**

- 可维护教练与课包商品；支付后得课包并可核销扣次  
- 可排场次；有生效会籍可代约；满员拒绝；取消释放名额  
- 可标记团课出席；教练仅见本人数据  
- 关键写操作有审计；测试覆盖售课 / 约课 / 满员 / 核销主路径
