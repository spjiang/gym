## 1. 设计原则

| 原则 | 说明 |
|---|---|
| **按受众分域** | 员工后台、会员端、开放 API 分开，权限与证书策略可独立 |
| **HTTPS 统一入口** | 公网只暴露 443（80 仅做跳转），业务端口不直接对外 |
| **同域反代 API** | Web 端继续用 `/api/v1`，避免 CORS；小程序/回调用独立 API 域 |
| **命名面向产品** | 对外避免 `h5`、`8080` 等技术词，对内文档可保留别名 |

## 2. 推荐域名规划（正式方案）

### 2.1 域名一览

| 用途 | 正式域名 | 说明 | 是否必须 |
|---|---|---|---|
| 管理后台 | `admin.guanyespace.com` | 健身房/清吧/平台运营后台 | ✅ |
| 会员端 | `m.guanyespace.com` | 会员 H5（选店、会籍、点餐等） | ✅ |
| 开放 API | `api.guanyespace.com` | 微信小程序、支付回调、设备/第三方 | ✅ |
| 品牌官网 | `www.guanyespace.com` | 品牌落地页与新闻/招聘/招商 | ✅ |
| 文件对象 | `file.guanyespace.com` | 公开图片（MinIO `public` 桶） | ✅ |
| 根域 | `guanyespace.com` | 301 → `www` | 建议 |

### 2.2 不推荐对外使用的命名

| 域名 | 问题 |
|---|---|
| `www.admin.guanyespace.com` | 多一层 `www`，证书与口述都更绕 |
| `h5.guanyespace.com` | 用户不懂；未来有小程序/App 时语义过时 |
| `123.56.26.229:8080` | 无 HTTPS、无品牌、小程序无法配置 |

### 2.3 对内别名（文档/运维可保留）

| 别名 | 等同 |
|---|---|
| admin | `admin.guanyespace.com` |
| member / m | `m.guanyespace.com` |
| www | `www.guanyespace.com` |

## 3. 流量架构

```
                    Internet (HTTPS :443)
                              │
                    ┌─────────▼─────────┐
                    │  主机 Nginx/Caddy   │  ← Let's Encrypt 证书
                    │  123.56.26.229      │
                    └─────────┬───────────┘
          ┌───────────────────┼───────────────────┬───────────────────┬─────────────┐
          │                   │                   │                   │             │
   admin.guanyespace.com  m.guanyespace.com  www.guanyespace.com  api.guanyespace.com  file.guanyespace.com
          │                   │                   │                   │             │
          ▼                   ▼                   ▼                   ▼             ▼
   主机:8080            主机:8081            主机:8082            主机:18000   主机:8900
   (frontend 容器)      (member-web 容器)    (website-web 容器)   (backend)    (MinIO public)
          │                   │                   │
          └──── /api/ ────────┴───────────────────┴──── 反代 ───► backend:8000
```

**说明：**

- `admin`、`m`、`www` 的 Nginx 已内置 `/api/` → `backend:8000`（见 `frontend/nginx.conf`、`member-web/nginx.conf`、`website-web/nginx.conf`）。
- `api` 域直达后端，供小程序与微信服务器回调，不经过前端静态资源。
- `file` 域只反代 MinIO 的 `public` 桶（匿名读图）；**不**挂 MinIO Console（控制台仅 `127.0.0.1:9001`）。
- Postgres `35432`、RabbitMQ、MinIO `8900` 等**不对公网开放**（同机 Nginx 访问 `127.0.0.1:8900`）。

## 4. DNS 解析

在域名服务商控制台添加（均为 **A 记录** → `123.56.26.229`）：

| 主机记录 | 记录类型 | 记录值 | TTL |
|---|---|---|---|
| `admin` | A | `123.56.26.229` | 600 |
| `m` | A | `123.56.26.229` | 600 |
| `api` | A | `123.56.26.229` | 600 |
| `www` | A | `123.56.26.229` | 600 |
| `file` | A | `123.56.26.229` | 600 |
| `@` | A | `123.56.26.229` | 600 |

若已申请 `www.admin`、`www.h5`，可保留并 **301 重定向** 到上表正式域名，避免两套并存。

## 5. 反向代理与 SSL（主机层 Nginx 示例）

在服务器安装证书后，于 `/etc/nginx/conf.d/guanyespace.conf`（路径按实际调整）。**反代目标用应用主机 IP + 端口**（运维侧若无法访问 `127.0.0.1`，请用 `123.56.26.229`；同机 Nginx 可用 `127.0.0.1`）：

```nginx
# admin — 管理后台
server {
    listen 443 ssl http2;
    server_name admin.guanyespace.com;

    ssl_certificate     /etc/letsencrypt/live/guanyespace.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/guanyespace.com/privkey.pem;

    client_max_body_size 16m;

    location / {
        proxy_pass http://123.56.26.229:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# m — 会员 H5
server {
    listen 443 ssl http2;
    server_name m.guanyespace.com;

    ssl_certificate     /etc/letsencrypt/live/guanyespace.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/guanyespace.com/privkey.pem;

    client_max_body_size 16m;

    location / {
        proxy_pass http://123.56.26.229:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# www — 品牌官网
server {
    listen 443 ssl http2;
    server_name www.guanyespace.com;

    ssl_certificate     /etc/letsencrypt/live/guanyespace.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/guanyespace.com/privkey.pem;

    client_max_body_size 16m;

    location / {
        proxy_pass http://123.56.26.229:8082;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# 根域 → www
server {
    listen 443 ssl http2;
    server_name guanyespace.com;
    ssl_certificate     /etc/letsencrypt/live/guanyespace.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/guanyespace.com/privkey.pem;
    return 301 https://www.guanyespace.com$request_uri;
}

# api — 小程序 / 支付回调 / 设备
server {
    listen 443 ssl http2;
    server_name api.guanyespace.com;

    ssl_certificate     /etc/letsencrypt/live/guanyespace.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/guanyespace.com/privkey.pem;

    client_max_body_size 16m;

    location / {
        proxy_pass http://123.56.26.229:18000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# file — 公开图片（MinIO public 桶；控制台不走此域）
server {
    listen 443 ssl http2;
    server_name file.guanyespace.com;

    ssl_certificate     /etc/letsencrypt/live/guanyespace.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/guanyespace.com/privkey.pem;

    client_max_body_size 16m;

    location / {
        # 与 FILE_PUBLIC_BASE_URL=https://file.guanyespace.com/public 对齐：
        # 浏览器访问 /public/{文件名}，MinIO path-style 同路径
        proxy_pass http://127.0.0.1:8900;
        proxy_set_header Host 127.0.0.1:8900;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# HTTP → HTTPS
server {
    listen 80;
    server_name admin.guanyespace.com m.guanyespace.com www.guanyespace.com guanyespace.com api.guanyespace.com file.guanyespace.com;
    return 301 https://$host$request_uri;
}
```

证书可用 **Certbot** 或云厂商免费证书；需覆盖 `admin` / `m` / `www` / 根域 / `api` / `file`。

## 6. 应用配置对照

### 6.1 服务器 `.env`（`/home/spjiangl/gym/.env`）

```env
APP_ENV=production

# 跨域（管理端 + 会员端；api 域一般不走浏览器 CORS）
CORS_ORIGINS=https://admin.guanyespace.com,https://m.guanyespace.com,https://www.guanyespace.com

# 商户获客二维码、短信链接等
MEMBER_WEB_PUBLIC_URL=https://m.guanyespace.com

# MinIO 公开读（与 Compose 中 MINIO_ENDPOINT=minio:9000 配合）
FILE_PUBLIC_BASE_URL=https://file.guanyespace.com/public
MINIO_ACCESS_KEY=请替换
MINIO_SECRET_KEY=请替换为强密码
```

**`MEMBER_WEB_PUBLIC_URL` 影响的外链（均由后端 API 生成，前端只展示）：**

| 场景 | 接口/模块 |
|------|-----------|
| 会员推广码链接与二维码 | `GET /members/{id}/promotion`、会员端「我的推广」 |
| 商户获客二维码 | `GET /merchants/{id}/acquisition-link` |
| 活动分享海报 | `GET /activities/{id}/share-link` |
| 餐饮桌码点餐 | 桌台二维码 URL |
| 微信 H5 支付回跳（dry-run/默认） | 支付配置 `h5_return_url` 缺省回退 |

本地开发保持 `.env` 中 `MEMBER_WEB_PUBLIC_URL=http://localhost:8081` 即可；线上改为 `https://m.guanyespace.com` 后**重启 backend** 生效，无需改代码。

```env
# 微信支付异步通知（路径以实际路由为准）
WECHAT_NOTIFY_URL=https://api.guanyespace.com/api/v1/payment/notify/wechat

# 生产建议
SEED_DEMO=false
UVICORN_RELOAD=0
```

## 7. 安全与防火墙

| 端口 | 公网 | 说明 |
|---|---|---|
| 443 | ✅ 开放 | HTTPS 唯一入口 |
| 80 | ✅ 开放 | 仅跳转 HTTPS |
| 8080 / 8081 / 8082 / 18000 | ⚠️ 按运维策略 | 应用监听 `0.0.0.0`，由 Nginx 反代；是否对公网开放由安全组/防火墙控制 |
| 8900 (MinIO S3) | ❌ | 仅本机 Nginx；生产 compose 绑 `127.0.0.1:8900` |
| 9001 (MinIO Console) | ❌ | 仅 `127.0.0.1`，不挂 `file.` |
| 35432 (Postgres) | ❌ | 仅内网 |
| 22 (SSH) | ⚠️ 限制 IP | 运维用 |

云安全组：入站仅 `80`、`443`（及受限的 `22`）。

## 8. 与旧地址的迁移

| 旧访问方式 | 新地址 |
|---|---|
| `http://123.56.26.229:8080` | `https://admin.guanyespace.com` |
| `http://123.56.26.229:8081` | `https://m.guanyespace.com` |
| `http://123.56.26.229:18000/api/v1` | `https://api.guanyespace.com/api/v1` |

切换步骤建议：

1. DNS 解析生效（ping / dig 验证）
2. 主机 Nginx + SSL 就绪
3. 复制 `.env.production.example` → `.env`，改密码与域名相关项
4. `docker compose -f docker-compose.prod.yml up -d --build`
5. 微信后台改合法域名；发版小程序
6. 与运维确认安全组/防火墙对 `8080/8081/8082/18000` 的访问策略（应用已监听 `0.0.0.0`）
